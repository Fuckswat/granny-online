# Granny Online

Захотелось поиграть в Granny с друзьями, поэтому я взялся за мультиплеерный мод.

Мультиплеерный мод для Granny. Можно создать лобби, выбрать роль Гренни или выжившего и играть вместе. Мод синхронизирует игроков, предметы, двери, капканы и другие события. Работает через BepInEx IL2CPP.

## Установка

Нужна установленная Granny под Windows. Мод готовился для Steam build 21006637 на Unity 6000.0.58f2. Для совместной игры у всех должна быть совместимая версия игры и одна сборка мода.

1. Распакуй комплект установщика и запусти `GrannyMP-install.bat`.
2. Установщик найдёт игру или попросит выбрать её папку, проверит версию и установит мод.
3. При желании согласись на установку Radmin VPN. В одной локальной сети он не нужен.
4. Запусти игру. Меню мультиплеера открывается на F1.

В комплекте уже версия 1.1.8, старые обновления ставить не нужно. При повторной установке настройки сохраняются, а предыдущая DLL копируется в `GrannyMP.dll.old`. Первый запуск BepInEx может занять время и потребовать интернет.

Если архива рядом с батником нет, он скачает его из релиза `v1.1.8`. Можно также положить `GrannyMP-payload-1.1.8.zip` рядом с батником. Перед установкой проверяется SHA-256 архива.

## Что есть

Лобби и роли, капканы и способности Гренни, ускорение и удар выжившего, настройки хоста и синхронизация игровых действий. В 1.1.8 включены исправления укрытий, предметов и камеры. Часть механик ещё требует проверки в игре.

## Сборка

Нужны .NET SDK 6, установленная Granny и BepInEx IL2CPP с созданными interop-библиотеками:

```powershell
dotnet build src/GrannyMP.csproj -c Release -p:GameDirectory="ПУТЬ_К_ПАПКЕ_GRANNY"
```

DLL в установщике взята из сохранённого обновления 1.1.8. Очищенные исходники заново не собирались, поэтому совпадение с DLL не подтверждено. Перед публикацией проверь права на встроенные картинки и звуки. Модель манекена в установщике сопровождается лицензией CC0. Игра и её interop-библиотеки в комплект не входят.

Мод неофициальный. Сетевой ключ не защищает сервер от посторонних, поэтому играйте с доверенными людьми.
